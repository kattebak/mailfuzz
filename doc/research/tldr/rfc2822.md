# RFC 2822 - Internet Message Format TLDR

> Specifies syntax for email messages between computer users. Supersedes RFC 822.

---

## Message Structure

```
Header-Field: value CRLF
Header-Field: value CRLF
CRLF                          <-- empty line separates header from body
Body text...
```

- **Character set**: US-ASCII (1-127)
- **Line terminator**: CRLF (CR=13, LF=10)
- **Line length**: MUST ≤998 chars, SHOULD ≤78 chars (excluding CRLF)

---

## Header Fields

```
field-name: field-body CRLF
```

- **Field name**: printable ASCII (33-126), no colon, case-insensitive
- **Field body**: any US-ASCII except bare CR/LF

### Folding (Long Headers)

Insert CRLF before any whitespace to split long headers:

```
Subject: This is a very long
 subject line
```

**Unfold** by removing CRLF immediately followed by WSP.

## Required Fields

| Field  | Count | Description           |
| ------ | ----- | --------------------- |
| `Date` | 1     | Origination date-time |
| `From` | 1     | Author mailbox(es)    |

## Common Optional Fields

| Field         | Max | Description                                           |
| ------------- | --- | ----------------------------------------------------- |
| `Sender`      | 1   | Transmitter (required if From has multiple addresses) |
| `Reply-To`    | 1   | Suggested reply address                               |
| `To`          | 1   | Primary recipients                                    |
| `Cc`          | 1   | Carbon copy recipients                                |
| `Bcc`         | 1   | Blind carbon copy (removed before delivery)           |
| `Message-ID`  | 1   | Unique message identifier (SHOULD include)            |
| `In-Reply-To` | 1   | Parent message ID(s)                                  |
| `References`  | 1   | Thread message IDs                                    |
| `Subject`     | 1   | Message topic                                         |

## Date-Time Format

```
[ day-of-week "," ] day month year hour:minute[:second] zone
```

**Examples**:

```
Fri, 21 Nov 1997 09:55:06 -0600
21 Nov 97 09:55:06 GMT
```

| Component   | Format                                          |
| ----------- | ----------------------------------------------- |
| day-of-week | Mon/Tue/Wed/Thu/Fri/Sat/Sun                     |
| day         | 1-2 digits                                      |
| month       | Jan/Feb/Mar/Apr/May/Jun/Jul/Aug/Sep/Oct/Nov/Dec |
| year        | 4 digits (2 digit obsolete)                     |
| time        | HH:MM[:SS]                                      |
| zone        | +/-HHMM (e.g., +0000, -0500)                    |

**Obsolete zones**: UT, GMT, EST, EDT, CST, CDT, MST, MDT, PST, PDT

## Address Formats

### Mailbox

```abnf
mailbox     = name-addr / addr-spec
name-addr   = [display-name] "<" addr-spec ">"
addr-spec   = local-part "@" domain
```

**Examples**:

```
user@example.com
"John Doe" <john@example.com>
John Doe <john@example.com>
```

### Local-part

- **dot-atom**: `user.name` (preferred)
- **quoted-string**: `"user name"` (when special chars needed)
- Allowed chars: `A-Z a-z 0-9 ! # $ % & ' * + - / = ? ^ _ ` { | } ~`

### Domain

- **dot-atom**: `example.com`
- **domain-literal**: `[192.168.1.1]`

### Group Address

```
group-name: addr1@example.com, addr2@example.com;
```

---

## Message-ID Format

```abnf
msg-id = "<" id-left "@" id-right ">"
```

**Example**: `<20210101120000.12345@mail.example.com>`

- MUST be globally unique
- Typically: `<timestamp.processid@hostname>`

## Lexical Tokens

### Atoms

```abnf
atext = ALPHA / DIGIT / "!" / "#" / "$" / "%" / "&" / "'" /
        "*" / "+" / "-" / "/" / "=" / "?" / "^" / "_" /
        "`" / "{" / "|" / "}" / "~"
atom  = 1*atext
```

### Quoted Strings

```abnf
quoted-string = DQUOTE *(qtext / quoted-pair) DQUOTE
quoted-pair   = "\" text
```

### Comments

```abnf
comment = "(" *(ctext / quoted-pair / comment) ")"
```

Comments are semantically invisible.

### Specials (Delimiters)

```
( ) < > [ ] : ; @ \ , . "
```

## Trace Fields

Added by mail transport, prepended to message:

```
Return-Path: <sender@example.com>
Received: from host (addr) by host; date-time
```

---

## Resent Fields

For forwarded/resent messages (prepended in blocks):

```
Resent-Date: ...
Resent-From: ...
Resent-To: ...
Resent-Message-ID: ...
```

## Key ABNF Summary

```abnf
message     = fields [CRLF body]
body        = *(*998text CRLF) *998text

fields      = *(orig-date / from / sender / reply-to /
               to / cc / bcc / message-id / in-reply-to /
               references / subject / comments / keywords /
               optional-field / trace / resent-*)

orig-date   = "Date:" date-time CRLF
from        = "From:" mailbox-list CRLF
to          = "To:" address-list CRLF
subject     = "Subject:" unstructured CRLF
message-id  = "Message-ID:" msg-id CRLF

date-time   = [day-of-week ","] date FWS time [CFWS]
date        = day month year
time        = hour ":" minute [":" second] zone
zone        = ("+" / "-") 4DIGIT

addr-spec   = local-part "@" domain
local-part  = dot-atom / quoted-string
domain      = dot-atom / domain-literal
```

## Threading (Reply Construction)

**In-Reply-To**: Parent's Message-ID

**References**: Parent's References + Parent's Message-ID

```
Original:    Message-ID: <A@host>
Reply:       In-Reply-To: <A@host>
             References: <A@host>
Reply-reply: In-Reply-To: <B@host>
             References: <A@host> <B@host>
```

## Quick Reference

### Minimal Valid Message

```
From: sender@example.com
Date: Sat, 18 Jan 2026 12:00:00 +0000

Hello, World!
```

### Full Example

```
From: John Doe <john@example.com>
To: Jane Smith <jane@example.com>
Cc: bob@example.com
Subject: Meeting tomorrow
Date: Sat, 18 Jan 2026 12:00:00 +0000
Message-ID: <20260118120000.12345@example.com>

Hi Jane,

Let's meet tomorrow at 10am.

John
```
